* Do NOT modify existing UI
* Do NOT add extra features

=====================================

=====================================

In communities table add:

* invite_code (unique string)

* Generate unique code

abc123xyz

https://yourdomain.com/community/join/{invite_code}

=====================================
STEP 4: JOIN PAGE

Create route:

/community/join/[invite_code]

=====================================
STEP 5: JOIN FLOW

When external user opens link:

---

IF user NOT logged in:

→ Redirect to login/signup

---

AFTER LOGIN:

* Fetch community using invite_code

=====================================
STEP 6: ACCESS CONTROL

After finding community:

* Check if community is approved

=====================================
STEP 7: JOIN REQUEST SYSTEM

User should NOT auto join

Instead:

* Create join request

community_members:

* id

* user_id
* status (pending/approved/rejected)
* created_at

STEP 8: OWNER APPROVAL

Community owner can:

* Approve / Reject members

STEP 9: UI

navigator.clipboard.writeText(url)
